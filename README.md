## StackDump [Chest Utility Stack Dumping]
#Current version: 0.3.1
It is functioning on the surface, but still many other features are pending + some common bug fixes.

**Description:**
StackDump will give utilities across clients to get rid of mining clutter such as cobblestone, or sorting chests automatically.
 - QuickSmelt option: Ability to automatically smelt, speeding up mining processes, also bringing XP, in case of fast paced gamemode.
 - In WIP

Other features planned:
 - Local configuration
 - Automatic Item Frame assignation
 - Visible informative Text Display
